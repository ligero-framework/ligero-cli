# Security Policy

## Reporting a Vulnerability

Please **do not open a public issue** for security problems. Use GitHub private
vulnerability reporting on this repository (*Security → Report a vulnerability*).

You will receive an acknowledgement within 7 days. Include a proof of concept and
the affected version or commit when possible.

Only the latest published version of Ligero receives security fixes. See the
[framework security policy](https://github.com/ligero-framework/ligero/blob/main/SECURITY.md)
for the full scope and deployment checklist.
